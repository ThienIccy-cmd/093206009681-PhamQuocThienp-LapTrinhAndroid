# Câu 3: Profile UI Android App

Ứng dụng hiển thị thông tin cá nhân (Profile UI) được xây dựng bằng **Jetpack Compose**.

## Hướng dẫn chạy ứng dụng

1. **Mở dự án trong Android Studio:**
   - Mở Android Studio -> Chọn **Open**.
   - Trỏ tới thư mục: `Tuan01/Cau3-ProfileUI/MyApplication`.
2. **Build và Run:**
   - Chờ Gradle Sync hoàn tất.
   - Chọn thiết bị/máy ảo Android (API 26+).
   - Nhấn **Run** (`Shift + F10`) để chạy ứng dụng.
